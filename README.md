## 🚧 Work in Progress

This project is currently under active development.

The goal of this project is to build an elastic machine learning inference serving platform using FastAPI, PyTorch, Docker, Prometheus, and Kubernetes. Core components such as the inference service, request dispatcher, monitoring, and containerization are being implemented and refined.

### Planned Features

* Asynchronous request dispatching
* Queue-based load management
* Scalable inference service deployment
* Kubernetes-based autoscaling
* Prometheus metrics and monitoring
* Health checks and fault tolerance
* Performance benchmarking and evaluation

### Current Status

* [x] FastAPI-based inference service
* [x] Dispatcher service with request queueing
* [x] Docker containerization
* [x] Kubernetes deployment
* [ ] Autoscaling implementation
* [ ] Monitoring dashboards
* [ ] Load testing and benchmarking
* [ ] Documentation completion

Contributions, feedback, and suggestions are welcome as the project evolves.
